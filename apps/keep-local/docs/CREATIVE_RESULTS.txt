IMPLEMENTED, NOT FULLY STRESS-VERIFIED
- Per-frame index checkpoints/resumption, opt-in/pause/remove controls,
  battery/storage/thermal scheduling, model unloading, incremental search.
- Stable relationships schema and source hashes during visual indexing.
- Model ZIP size/hash validation and staged installation. Full installation fault
  matrix, abrupt process-death stress, sustained resource behavior remain pending.

UNVERIFIED / INCOMPLETE
- Real person-eating-noodles video versus noodles-on-table hard negatives.
- Action boundaries, identity recognition, scene-change detection, saved-audio
  transcription, semantic document embeddings, collections, trimming and
  source-clip export with collection manifests.
- Physical-device installation/Play Protect, ChatGPT/other third-party receipt,
  battery/thermal behavior, GPU/NPU compatibility and large-library latency.
- Old com.keep.local private recordings cannot be read by this separate package.

NEXT MILESTONE

hard negatives and a physical flagship. Select an accelerated/stronger model from

it does not claim completion of the full A-D roadmap or the main action demo.
