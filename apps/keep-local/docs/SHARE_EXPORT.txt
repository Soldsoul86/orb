Build behavior:
- Missing key: unsigned product APK. It cannot be installed or used as an update.
- Provided key: checks pinned original certificate before packaging.
- Configure KEEP_LOCAL_KEYSTORE, KEEP_LOCAL_STORE_PASSWORD, KEEP_LOCAL_KEY_ALIAS,
  KEEP_LOCAL_KEY_PASSWORD securely outside Git. No secrets are embedded/uploaded.
- CI signs disposable test copies ONLY for emulator verification, including a
  re-signed baseline. They cannot upgrade the original signed installation.
- CI explicitly checks that the real original rejects a mismatched certificate,
  and that its seeded recording remains intact after rejection.

Implementation:
- Explicit Share uses ACTION_SEND, MIME, EXTRA_STREAM and ClipData with a
  temporary read grant. Non-exported item provider serves a seekable read-only
  file descriptor, no raw paths or directory grants.
- Photos/video: MediaStore pending insertion then stream, close, publish in
  Pictures/Keep Local or Movies/Keep Local. Existing names are queried and a
  numeric suffix is chosen under a lock. Duplicate files are not overwritten.
- All media: Save to Files via ACTION_CREATE_DOCUMENT, local-only preference.
- Export filenames use the saved title, safe extension and bounded UTF-8 length.
- Copying runs off the UI thread with 64 KiB buffer, cancellation and partial
  output cleanup; original file and metadata are never mutated by export.
- Rotation retains an active copy without retaining the old Activity. Leaving
  the Activity cancels; process death can leave an invisible pending MediaStore
  row that Android expires. SAF providers may retain a partial file on process
  death or if deletion fails. No recovery of original content is needed.
- No permissions added; app has no INTERNET or broad storage permission.

Read-only recovery route for the installed debug build (physical phone UNVERIFIED):
1. Stop all Keep Local recordings. Keep the app installed and its data intact.
2. On a trusted computer install Android platform-tools and Python 3.
3. Connect the phone by USB, enable USB debugging, and authorize that computer.
4. Run adb devices to identify the device serial.
5. Run:
   python3 scripts/recover-existing-media.py --serial YOUR_SERIAL --title "CAD Test" --output "CAD Test.mp4" --recordings-stopped
6. If duplicate titles exist, rerun with the displayed --id. Existing output
   files are never overwritten. The script reads the database and original
   via run-as; it never writes to app storage or changes the installation.
7. Copy the verified MP4 back to the phone's Download folder through USB, then
   choose it from ChatGPT's attachment picker if that app supports MP4 uploads.
   Actual ChatGPT upload acceptance is not verified.
8. Reopen Keep Local. Disable USB debugging when finished if desired.

This route requires a computer and an authorized USB connection. It is not an
on-phone replacement for the requested update and does not meet that criterion.
