A: SQLite v1 -> v2 adds assets, representations and asset_relationships only.
Existing memories, IDs, FTS, metadata and paths are retained. Asset UUIDs are
assigned once by migration/insert trigger. Representations retain source ID,
model version, modality, time range and generation time. The original remains
unchanged. Explicit deletion cascades derived rows. Original SAF source URI and
local reference are separate. SHA-256 detects equal content during indexing;
duplicates are not automatically deleted or merged. Relationship schema is ready
for derivatives; collections and trimming UI are not yet implemented.

B: CLIP image and text embeddings, cosine ranking, image pixels only. Video
frames sampled every 2 seconds; result intervals describe sampling, NOT verified
action boundaries. Existing text/metadata/OCR results are labeled separately.
A score is similarity, not calibrated probability. No face identity inference.
"Me" cannot identify a subject; explicit notes are the only identity context.

Visual model is optional. Install visual-model-pack.zip using Visual memory.
Its exact byte size is shown before installation; each file is size/hash checked
against a manifest packaged by the build. No INTERNET permission or uploads.
Without the model: capture, import, OCR, text/metadata search and exports work.
With the model: opt in to index authorized private library assets, then search.
Progress is committed per frame and resumed after reopening/restart. Android
JobScheduler waits for sufficient battery/storage; severe heat pauses work.
Pause and remove controls preserve originals. No continuous capture is added.
Models unload when each search/index batch finishes. One image/frame is decoded
at a time. Images respect decoder orientation. Storage, not a fixed 1 GiB cap,
limits imports. No chipset assumptions or entry-level phone target remain.

Validation corpus: real scikit-image sample photos of cat, coffee, astronaut,
and rocket, with opaque filenames and blank notes/OCR. A synthetic montage
places cat at 0-4s, coffee at 4-8s and astronaut at 8-12s. It is NOT a real action
video. Tests compare CLIP tokenizer against a reference tokenizer, measure visual
hit rate and montage timestamp, indexing/search time and memory samples. Emulator
metrics are not flagship-device, battery or thermal benchmarks. The noodles
versus noodles-on-table action demo remains UNVERIFIED; no claims based on this
montage establish temporal action recognition.

Build: GitHub Actions fetches pinned weights, builds/tests the app, creates
model pack and requests a detached APK signature. The recovered private key stays
in the private workspace. Only its public certificate and signatures can enter
Git. The final workflow reuses exact unsigned bytes and verifies the certificate
and actual in-place upgrade against the previously delivered signed APK.
