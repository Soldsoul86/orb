Compatible scope: retain JOSE/Signal/key formats and migration semantics. Add optional provider invitation records and API operations, per-invitation access-duration metadata enforced when creating existing signed approval grants, and a dedicated PostgreSQL schema so the existing relay can host the extension durably without rewriting legacy tables. Cancelling an invitation stops unapproved requests; ending an accepted conversation is a separate explicit revocation.
